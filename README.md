# Ochoa Parts · Plataforma B2B

Reemplazo de `ochoaparts.com`: catálogo de instrumentación y control industrial, pedidos con pago manual verificado por
el staff y panel administrativo.

| Carpeta     | Contenido                                                                                                 |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| `apps/web/` | Angular 20 con las tres propuestas de diseño del frontend. El cliente eligió la **propuesta A** (archivo) |

El código de la plataforma vive en repositorios privados, ignorados aquí:

- **Backend** (API y su documentación): `ochoa-parts-backend/`.
- **Frontend** (tienda pública basada en la propuesta A y panel administrativo, dos aplicaciones aisladas):
  `ochoa-parts-frontend/`.

Este repositorio es **público**: los datos del cliente (`INVENTARIO*.xlsx`, `migracion-datos/`), el kit licenciado de
Flowbite Pro y las fuentes internas de diagramas están en `.gitignore` y nunca se versionan.
